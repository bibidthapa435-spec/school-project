How to Add Date & Time to Popup Notices

1
Click "Add Popup Notice"

Go to the Django admin to create a new popup notice with your content.

2
Set Schedule Dates

In the Schedule section, click the "Now" button to instantly set the current date and time, or use the date picker to select a specific date.

3
Leave Blank for No Limit

Leave Start Date blank to show immediately, or leave End Date blank to show indefinitely.

Tip: The popup will only be visible to visitors when it's active AND the current date/time is between the start and end dates you set.
